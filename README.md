# LP 영상 만들기

녹음파일과 배경·LP 라벨 이미지로 회전하는 LP 영상을 만드는 모바일 우선 PWA입니다.

## 특징

- m4a, mp3, wav 등 브라우저가 재생할 수 있는 오디오 입력
- 배경 사진을 LP 라벨에도 자동 적용하고, 원할 때 라벨 사진만 별도로 교체
- 인스타그램 스토리 9:16, 피드 4:5, 정사각형 1:1, 가로 16:9 출력
- 텍스트를 LP 바로 아래 또는 화면 하단에 배치
- 제목·설명 각각 왼쪽/가운데/오른쪽 정렬 및 가로·세로 위치 조절
- 제목·설명 각각 색상·크기·투명도와 두 텍스트 사이 간격 조절
- 추가 텍스트를 최대 6개까지 만들고 각각 정렬·크기·가로·세로 위치·색상·투명도 조절
- 배경과 LP 라벨 사진의 위치 이동 및 확대를 각각 조절
- 배경 색상 필터·농도와 필름 그레인 강도 조절
- 모바일에서 조절 항목을 스크롤해도 안전영역 아래에 미리보기 고정
- 빛 방향을 조절하고 LP 외곽 그림자와 홈 하이라이트가 회전에 맞춰 변화
- 720p 용량 절약 / 1080p 고화질
- 가로폭 1080px·15fps·낮은 비트레이트의 빠른 저용량 모드
- 완성 영상을 아이폰 공유 시트로 저장
- 현재 프로젝트의 녹음·사진·모든 편집 설정을 기기에 저장하고 앱 재실행 시 자동 복원
- 아이폰 Safari에서도 녹음 오디오 트랙을 영상에 안정적으로 포함
- 영상 생성 중 다른 앱으로 이동하면 영상·소리를 함께 안전하게 일시정지하고, 복귀 후 버튼으로 이어서 생성
- LP 회전을 녹음 재생 시간축에 동기화해 일시정지·재개 뒤에도 회전과 소리가 어긋나지 않음
- 영상 생성은 독립 프레임 타이머와 수동 캔버스 프레임 요청을 사용해 녹음이 끝날 때까지 LP 회전을 계속 기록
- 정적 배경은 한 번만 처리하고 LP 회전 레이어만 갱신해 장시간 생성 시 기기 부담을 줄임
- 업로드 없이 브라우저 안에서만 처리
- 홈 화면 설치 및 오프라인 앱 셸 지원

## 주의사항

영상은 녹음 길이만큼 실시간으로 생성됩니다. 생성 중 다른 앱으로 이동하거나 화면을 끄면 자동으로 일시정지됩니다. 앱으로 돌아와 `영상 만들기 계속`을 누르면 이어서 생성되며, 앱을 완전히 종료하면 다시 만들어야 합니다. 브라우저가 MP4 녹화를 제공하지 않으면 WebM으로 저장될 수 있습니다.

## 개발

```bash
npm install
npm run dev
```

```bash

```
