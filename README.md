# LP 영상 만들기

녹음파일과 썸네일 이미지 한 장으로 회전하는 LP 영상을 만드는 모바일 우선 PWA입니다.

## 특징

- m4a, mp3, wav 등 브라우저가 재생할 수 있는 오디오 입력
- 사진을 LP 라벨과 흐린 배경으로 자동 배치
- 인스타그램 스토리 9:16, 피드 4:5, 정사각형 1:1, 가로 16:9 출력
- 텍스트를 LP 바로 아래 또는 화면 하단에 배치
- 제목·설명 각각 왼쪽/가운데/오른쪽 정렬 및 가로·세로 위치 조절
- 추가 텍스트를 최대 6개까지 만들고 각각 정렬·크기·가로·세로 위치 조절
- 배경과 LP 라벨 사진의 위치 이동 및 확대
- 배경 색상 필터·농도와 필름 그레인 강도 조절
- 모바일에서 조절 항목을 스크롤해도 안전영역 아래에 미리보기 고정
- 톤암 없이 LP만 깔끔하게 회전
- 720p 용량 절약 / 1080p 고화질
- 가로폭 1080px·15fps·낮은 비트레이트의 빠른 저용량 모드
- 완성 영상을 아이폰 공유 시트로 저장
- 업로드 없이 브라우저 안에서만 처리
- 홈 화면 설치 및 오프라인 앱 셸 지원

## 주의사항

영상은 녹음 길이만큼 실시간으로 생성됩니다. 생성 중에는 화면을 끄거나 다른 앱으로 이동하지 않는 것이 안전합니다. 브라우저가 MP4 녹화를 제공하지 않으면 WebM으로 저장될 수 있습니다.

## 개발

```bash
npm install
npm run dev
```

GitHub Pages용 정적 빌드:

```bash
npm run build:pages
```
